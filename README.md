# *Project Objective*

Assume the market return follows a normal distribution:  
*Rₘ ~ N(15%, 4²)*

The risk-free rate (Rᶠ) is *2%*.



# *Tasks*

1. *Construct an equally weighted portfolio using 20 given stocks.*

2. *Calculate the portfolio return (Rₚ).*

3. *Simulate 10,000 such portfolio returns using Monte Carlo simulation.*

4. *Compute the expected portfolio return E(Rₚ) and portfolio standard deviation σₚ from the simulation.*

5. *Manually calculate σₚ, assuming that idiosyncratic risk is diversified away.*

6. *Manually calculate E(Rₚ) using CAPM.*

7. *Compare the manual results with the Monte Carlo simulation to verify alignment.*
